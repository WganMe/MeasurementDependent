## What the maps show

Each map displays:

- The OpenStreetMap street and footway network within 7 km of the core
  centre (157,303 nodes, 176,388 edges, retrieved 2026-11-13).
- The sensor locations for that year, with popups carrying the
  identifier, theme and row count.
- Sensor clustering (MarkerCluster) for readability at low zoom.

## How the maps are made

The maps are generated by the public Kaggle notebook
[wganme/measurement-dependent](https://www.kaggle.com/code/wganme/measurement-dependent)
from the public dataset
[wganme/measurementdependent](https://www.kaggle.com/datasets/wganme/measurementdependent),
using [Folium](https://python-visualization.github.io/folium/) and
[Leaflet.js](https://leafletjs.com/).

No external scripts or local tools are used. Every map can be
reproduced by running the notebook on Kaggle.

## Data sources

- **Sensor locations and metadata:** Newcastle Urban Observatory archive
  census, built from 914 archive files (3.6 billion readings, 74.7 GB).
  Published by Newcastle University under CC BY 4.0
  (DOI: [10.25405/data.ncl.c.5059913](https://doi.org/10.25405/data.ncl.c.5059913)).

- **Street network:** OpenStreetMap, retrieved 2026-11-13.
  Copyright OpenStreetMap contributors, Open Database Licence (ODbL) 1.0.
  <https://www.openstreetmap.org/copyright>

- **Base map tiles:** OpenStreetMap tile servers, loaded at runtime.
  Copyright OpenStreetMap contributors, CC BY-SA 2.0.
